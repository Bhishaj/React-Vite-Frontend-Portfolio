# Bhishaj Kumar Sharma — Portfolio

A personal portfolio website showcasing my work in Network Security, Zero Trust Architecture, and Cloud Security — built as a fully responsive single-page application.

## About This Project

This portfolio brings together my professional background, technical skill set, and flagship project work in one place — including my Zero Trust Secure Web Gateway capstone, hands-on security labs, certifications, and technical write-ups on Zscaler and network security concepts.

### Sections
- **Hero** — introduction and quick links
- **About** — professional summary and career focus
- **Technical Skills** — Zscaler, networking, firewalls, cloud, security tooling
- **Professional Experience** — role history and key achievements
- **Featured Projects** — including the Zero Trust SWG platform
- **Security Labs** — hands-on lab work across Zscaler, networking, VPN/IPsec, and AWS
- **Certifications** — completed, in-progress, and planned
- **Education** — academic background
- **Technical Blog** — short-form notes on Zero Trust and network security
- **Resume** — inline viewer and download
- **Contact** — direct form and social links

## Running Locally

```bash
# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build

# Preview the production build
npm run preview
```

## Project Structure

```
portfolio/
├── public/
│   └── assets/              # Images, resume PDF
├── src/
│   ├── App.tsx               # Root component — assembles all sections
│   ├── main.tsx               # Application entry point
│   ├── data/                  # Content (skills, experience, projects, etc.)
│   ├── types/                 # Shared TypeScript interfaces
│   ├── hooks/                 # Custom hooks (scroll-spy navigation)
│   └── components/
│       ├── layout/             # Navbar, Footer
│       ├── sections/           # Page sections (Hero, About, Skills, ...)
│       └── ui/                 # Reusable UI primitives (Card, Badge, Button, ...)
├── index.html
├── tailwind.config.js
└── vite.config.ts
```

---

## Deployment

This project is deployed on **Vercel** with continuous deployment enabled — every push to `main` automatically triggers a new build and deploy.
